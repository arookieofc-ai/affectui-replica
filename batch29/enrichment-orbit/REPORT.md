# Enrichment Orbit — replica report

## What was built
Single standalone `index.html` (22KB, no external deps) replicating affectUI **Enrichment Orbit** (`enrichment-orbit`): a Grok tile inside two rings with orbiting comets and data nodes.

- Center: 52x52 rx12 tile at (134,94) + Grok mark (26px at 147,107, viewBox `0 0 33.4 32`, two paths verbatim).
- Rings: r56 (opacity .45) + r80, center 160,120, `viewBox 0 0 320 240`, stroke `#E4E7EC` 1.2.
- Comets: outer arc `M114.1 54.5 A80 80 0 0 1 205.9 54.5`, inner arc `M120.4 80.4 A56 56 0 0 1 199.6 80.4`, gradient `#FF6B5C(0) / #FFB89E / #C8A8E5 / #A8B5FF`, 1.6px round, 7s linear infinite (inner reversed).
- Nodes: 3x r17 bubbles at (160,40) with icon `translate(154 34) scale(0.0288)` (path verbatim), delays `0s / -7.33s / -14.66s`, 22s orbit + reverse upright.
- Label verbatim: `A Grok tile with data nodes orbiting around it` as svg `aria-label` + visible caption.
- Clean-room: all HTML/CSS/JS re-authored; only geometry numbers, gradient stops, path `d`s, delays, and label copied as demo data.

## Page chrome (spec tokens)
- Tokens via CSS vars for every colour; light (`surface #ffffff / page #fafaf9 / ink #171717 / muted #78716c / subtle #f5f5f4 / border #e7e5e4`) and dark (`surface #1c1c1f / page #101012 / ink #ededed / muted #a1a1aa / subtle #26262a / border #2e2e33`).
- Header: project name + `Enriching · 3 live` pill + `3 nodes orbiting / enriched` meta; context `44k / 200k tokens` with thin 3px bar, right-aligned.
- Controls: theme toggle (sun/moon, top-right), Pause/Play, Details toggle, 3 node chips. Hover/focus highlights ring, click selects + opens details, Esc closes, Enter/Space on SVG nodes works, focus-visible outlines.
- Ticker: 1s `tick()` updates status/enriched/lap/records via `textContent` only.
- Responsive: `<=640px` stacks to single column.

## v4 / v5 compliance
- Noflash: `<head>` starts with `/*noflash*/` script (stored `enrichment-orbit-theme` else `prefers-color-scheme`), then `html{background:#fafaf9}html[data-theme="dark"]{background:#101012}`, then `<meta name="color-scheme" content="light dark">`.
- In-place only: DOM built once (`buildNodes()`); `tick()/selectNode()/setTheme()/highlight()` mutate `textContent/class/attributes/style` on existing nodes. Zero `innerHTML` in file.
- v5: all `:hover` inside `@media (hover:hover) and (pointer:fine)`; `html{-webkit-tap-highlight-color:transparent}`; `body{font-variant-numeric:tabular-nums}`; concentric radius (card 16 = inner 10 + 6 inset); shadow for elevation + border for structure; art frame has 1px inset outline `rgba(0,0,0,.1)` / `rgba(255,255,255,.1)`; icon buttons use `-2px` optical nudge.
