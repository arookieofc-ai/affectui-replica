Running Now — live header pill for background tasks

The pill summarises live work (3 running + 1 need you). Open it to see progress rings, step labels, pause / resume and open actions. A task ticks forward every 1900ms; the loop resets every 14 ticks.

Keyboard: ↓/↑ on the pill opens the panel, Esc closes it, arrows move between rows inside the panel.
